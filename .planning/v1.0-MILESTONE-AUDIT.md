## Blocker Details

### Blocker 1: SHOW-03 — Run Smoke Test broken (2 fixes required)

**Fix 1 — Add `workflow_dispatch:` to ci.yml**

`.github/workflows/ci.yml` — add under `on:`:
```yaml
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
  workflow_dispatch:   # ← add this
```

Without this, `POST /api/run-tests` → GitHub API → 422 Unprocessable Entity.

**Fix 2 — Fix response parsing in /api/run-tests**

`src/app/api/run-tests/route.ts` — the GitHub `workflow_dispatch` endpoint returns **204 No Content** (no body). Calling `res.json()` on it throws. The `return_run_details` parameter does not exist in the GitHub API. After dispatch succeeds (204), use a secondary GET to `/repos/{owner}/{repo}/actions/runs?event=workflow_dispatch&branch=main` to find the new run ID.

### Blocker 2: CONT-05 — Double footer on /about

`src/app/layout.tsx` renders `<Footer variant="compact" />` on every page.
`src/app/about/page.tsx` also renders `<Footer variant="full" />` inside its return JSX.
Result: two `<footer role="contentinfo">` elements on `/about`.

**Fix options:**
- Remove `<Footer>` from `layout.tsx`; each page renders its own variant (preferred)
- Remove `<Footer>` from `about/page.tsx`; use only the layout compact footer on all pages
- Conditionally suppress layout footer for /about via layout segment config
