### Task 2: Run `pnpm typecheck` and fix any type errors

<action>
Run:

```bash
pnpm typecheck
```

**Expected:** exits 0.

**Common failure modes and fixes:**

1. **`@types/mdx` not installed** — causes `Cannot find module 'mdx/types'`
   - Fix: `pnpm add -D @types/mdx`

2. **Implicit `any` on MDX component props** in `mdx-components.tsx`
   - `h1: ({ children }) => ...` — `children` may be typed as `React.ReactNode`. If TypeScript complains, add explicit type:
     ```tsx
     h1: ({ children }: { children?: React.ReactNode }) => <h1 className={styles.proseH1}>{children}</h1>,
     ```

3. **`href` possibly undefined** on the `a` component mapping in `mdx-components.tsx`
   - Fix:
     ```tsx
     a: ({ href, children }: { href?: string; children?: React.ReactNode }) => (
       <a href={href} className={styles.proseA}>{children}</a>
     ),
     ```

4. **`Footer` prop type error** — `variant` must be `'compact' | 'full'`
   - Check `src/components/layout/Footer.tsx` — the `FooterProps` interface must define `variant: 'compact' | 'full'`

Fix all type errors, then re-run `pnpm typecheck` until it exits 0.
</action>
