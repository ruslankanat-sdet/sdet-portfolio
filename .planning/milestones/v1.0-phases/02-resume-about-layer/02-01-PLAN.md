### Task 4: Fix `globals.css` — overflow and layout utility classes

<action>
Edit `src/app/globals.css`. Make the following two changes:

**Change A — Split the `html, body` rule (lines 132–142):**

Replace:
```css
html,
body {
  height: 100%;
  overflow: hidden;
  background: var(--bg-deepest);
  font-family: var(--ui);
  font-size: 13px;
  color: var(--text);
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
}
```

With:
```css
html {
  height: 100%;
}

body {
  height: 100%;
  /* overflow: hidden removed — controlled per layout via .site-body */
  background: var(--bg-deepest);
  font-family: var(--ui);
  font-size: 13px;
  color: var(--text);
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
}
```

**Change B — Add `.site-body` and `.site-main` utility classes** immediately after the `body` block above (before the root background gradient section):

```css
/* ─────────────────────────────────────────────────────────────
   Layout utilities — applied via root layout.tsx
   .site-body: flex column, full viewport height, contains scroll
   .site-main: fills remaining space between header and footer
   ───────────────────────────────────────────────────────────── */
.site-body {
  display: flex;
  flex-direction: column;
  height: 100dvh;
  overflow: hidden; /* prevents outer body scroll; IDE landing stays fully contained */
}

.site-main {
  flex: 1;
  min-height: 0; /* critical: allows flex child to shrink below content size */
  overflow: hidden; /* IDE landing: scroll is managed inside IDEShell; /about overrides with scrollContainer */
}
```

Rationale: Removing `overflow: hidden` from `html, body` and moving it to `.site-body` gives us per-page control. The IDE landing page gets the same locked behavior because `layout.tsx` applies `.site-body` to `<body>`. The `/about` page's scrollContainer div (Plan 02-02) gets `overflow-y: auto` to create its own scroll region inside `.site-main`.
</action>
