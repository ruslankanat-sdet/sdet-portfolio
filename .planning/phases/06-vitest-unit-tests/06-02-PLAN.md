# Plan 06-02: Tokenizer Unit Tests

## Objective

Write Vitest tests for `src/lib/syntax-highlighter.ts` that prove the TypeScript tokenizer assigns correct token class names to representative TS syntax patterns (TEST-01). Tests verify the tokenizer's logic, not rendered HTML — they inspect the React element objects returned by `tokenize()` directly, which requires no DOM and no React renderer.

## Background

`tokenize(src, lang)` returns `ReactNode[]`. Each colored token is a React element created with `createElement('span', { className: 'tk-<cls>', key }, text)`. Plain whitespace and identifiers are returned as raw strings. Tests verify token classification by reading `element.props.className` and `element.props.children` from the returned array — this is valid because React elements are plain objects (no rendering needed).
