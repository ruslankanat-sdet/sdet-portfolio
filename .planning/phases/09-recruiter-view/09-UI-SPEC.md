## Interaction Contracts

### Mode switching
- Both "Engineer view ↗" pill (masthead) and "Open the IDE →" (footer) call the same handler
- Handler: `localStorage.setItem('resume-mode', 'ide')` then updates parent `mode` state
- No page navigation — in-place re-render via ResumeGate state (already implemented)
- `onSwitchToIDE` prop is passed from `ResumeGateInner` to `RecruiterView`

### Download PDF
- "Download PDF ↓" button calls `window.print()` — do NOT navigate or fetch
- Use `onClick: (e) => { e.preventDefault(); window.print(); }`

### Availability pulse animation
- `avail-pulse` keyframe on the `::before` dot pseudo-element
- Duration: 1.8s, timing: ease-in-out, iteration: infinite
- Gate behind `@media (prefers-reduced-motion: no-preference)`

### Hover states
- Masthead switch pill: border + text + bg tint in forest, arrow nudge up-right
- Primary CTA: `translateY(-1px)` lift + deeper forest bg
- Secondary CTA: forest-soft bg tint
- Skill pills: forest border + bg + text
- Footer switch: forest text + underline
- Contact item values: forest text
- Contact large email link: deeper forest underline

### Keyboard / accessibility
- Masthead switch: `<button type="button">` — keyboard focusable, Enter/Space trigger
- Footer switch: `<button type="button">` — same
- Download PDF: `<a>` with `onClick` interceptor OR `<button type="button">`
- `aria-label` on LogoMark container: not needed (`aria-hidden` on SVG is sufficient)
- All interactive elements visible focus ring (browser default is acceptable; do not remove outline)
- Availability pill is presentational — no role needed
