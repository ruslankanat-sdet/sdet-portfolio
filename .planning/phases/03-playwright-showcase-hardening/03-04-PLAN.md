## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> repo source | Runner checks out the commit being tested; no external code is fetched beyond pinned action versions |
| Playwright test process -> localhost server | Tests run against a server built and started inside the runner; no external network calls beyond browser bootstrapping |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-CI | Tampering | CI workflow tamper-resistance | mitigate | All actions pinned to major versions (checkout@v4, setup-node@v4, action-setup@v4, upload-artifact@v4) — official GitHub-maintained actions only; no third-party marketplace actions added. |
| T-03-CIToken | Information Disclosure | Default GITHUB_TOKEN scope in playwright-tests job | accept | playwright-tests job does not need elevated permissions — uses default read-only GITHUB_TOKEN provided by Actions; no secrets passed to test process; no secret env vars defined in this job. |
| T-03-CIArtifact | Information Disclosure | Uploaded playwright-report artifact | accept | HTML report contains test failure screenshots and console logs from a localhost server with no real data — no PII, no secrets. Retention 7 days bounds exposure. |
</threat_model>
