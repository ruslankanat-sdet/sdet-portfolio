    Append a new top-level job deploy-report to .github/workflows/ci.yml after the playwright-tests job.
    The job must have the following structure (match existing indentation: 2-space YAML):

      deploy-report:
        needs: playwright-tests
        if: ${{ !cancelled() }}
        runs-on: ubuntu-latest
        permissions:
          pages: write
          id-token: write
        concurrency:
          group: pages
          cancel-in-progress: false
        environment:
          name: github-pages
          url: ${{ steps.deployment.outputs.page_url }}
        steps:
          - name: Download Playwright report
            uses: actions/download-artifact@v4
            with:
              name: playwright-report
              path: playwright-report/

          - name: Configure Pages
            uses: actions/configure-pages@v4

          - name: Upload to Pages
            uses: actions/upload-pages-artifact@v3
            with:
              path: playwright-report/

          - name: Deploy to GitHub Pages
            id: deployment
            uses: actions/deploy-pages@v4

    Key constraints to enforce:
    - needs: playwright-tests (not quality-gate — report job depends on the test job finishing)
    - if: ${{ !cancelled() }} (deploy report even if tests fail, so failed test reports are visible)
    - concurrency group: pages with cancel-in-progress: false (prevents Pages deployment from
      being cancelled by the top-level concurrency group that uses cancel-in-progress: true)
    - No checkout step — the artifact is downloaded directly, no source code needed
    - Artifact name 'playwright-report' must exactly match the name in the upload-artifact step
      of playwright-tests (line 86: name: playwright-report)
  </action>
