# Quick Task 260523-q02: Fix CONT-05 Double Footer

## Problem

`layout.tsx` renders `<Footer variant="compact" />` on every page. `about/page.tsx` also renders
`<Footer variant="full" />` inside its `scrollContainer`. Result on `/about`: two
`<footer role="contentinfo">` elements — one inside `site-main` (full, scrolls with content),
one outside (compact, fixed below main). Duplicate ARIA landmark + visual double footer.

## Fix

**Task 1: Remove Footer from layout.tsx**

- Remove `import { Footer } from '@/components/layout/Footer';`
- Remove `<Footer variant="compact" />` from the body JSX

Rationale: The landing page uses IDEShell which has a StatusBar — no standalone footer needed.
`/about` already has a full footer inside its scroll container. Any future pages can add their
own footer. Keeping the layout footer was the architectural mistake.

**Task 2: Fix copyright year in Footer.tsx**

`Footer.tsx` line 84 shows `© 2024 Ruslan Kanatbek`. Update to `© 2026`.

**Commit:** `fix(02-01): remove duplicate layout footer; fix copyright year (CONT-05)`
